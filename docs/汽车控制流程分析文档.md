# FreeMS2 汽车控制流程分析文档

## 1. 概述

本文档通过代码分析详细说明 FreeMS2 如何控制汽车发动机运行，实现汽车的行驶控制。系统通过精确的时序控制、传感器数据采集和计算，最终控制燃油喷射和点火，使发动机产生动力驱动汽车。

## 2. 控制流程总览

### 2.1 完整控制链路

```
发动机位置传感器 → 位置解码 → ADC采样 → 变量生成 → 计算 → 调度 → 执行器控制
     ↓                ↓          ↓         ↓        ↓       ↓         ↓
   曲轴/凸轮轴      RPM计算    传感器值   物理量   脉宽/角度  定时器   喷油器/火花塞
```

### 2.2 关键代码文件

- **位置解码**: `Simple.c`, `MissingTeeth.c`, `NipponDenso.c` 等
- **传感器处理**: `coreVarsGenerator.c`
- **计算**: `fuelAndIgnitionCalcs.c`
- **调度**: `Simple.c` 中的 `PrimaryRPMISR()`
- **执行**: `injectorISR.c`, `injectionISRs.c`

## 3. 第一阶段：发动机位置检测与同步

### 3.1 位置传感器输入

系统通过曲轴位置传感器（Crank Position Sensor）和凸轮轴位置传感器（Cam Position Sensor）检测发动机位置。

**代码位置**: `src/Simple.c` - `PrimaryRPMISR()`

```c
void PrimaryRPMISR(){
    /* 清除输入捕获通道的中断标志 */
    TFLG = 0x01;
    
    /* 保存所有相关可用数据 */
    unsigned short codeStartTimeStamp = TCNT;      /* 保存当前定时器计数值 */
    unsigned short edgeTimeStamp = TC0;            /* 保存边沿时间戳 */
    unsigned char PTITCurrentState = PTIT;         /* 保存端口T的值 */
```

**工作原理**:
- 曲轴位置传感器产生脉冲信号
- 每个脉冲对应曲轴的一个特定角度位置
- 定时器的输入捕获功能捕获每个脉冲的精确时间
- 通过脉冲间隔计算发动机转速（RPM）

### 3.2 RPM 计算

**代码位置**: `src/Simple.c` 第 104-106 行

```c
// = 60 * (1000000 / 0.8)
#define ticksPerMinute   75000000 // 这是正确的

*RPMRecord = (unsigned short) (ticksPerMinute / timeBetweenSuccessivePrimaryPulses);
```

**计算原理**:
- `ticksPerMinute`: 每分钟的定时器计数 = 60秒 × (1秒/0.8微秒) = 75,000,000
- `timeBetweenSuccessivePrimaryPulses`: 连续两个脉冲之间的时间（定时器计数）
- RPM = 75,000,000 / 脉冲间隔

**示例**:
- 如果脉冲间隔 = 50,000 个定时器计数（0.8μs × 50,000 = 40ms）
- RPM = 75,000,000 / 50,000 = 1,500 RPM

### 3.3 同步状态管理

**代码位置**: `src/Simple.c` 第 79 行

```c
// 设置为已同步（对于沃尔沃总是这样，因为实际上不可能失去同步）
coreStatusA |= PRIMARY_SYNC;
```

**作用**:
- `PRIMARY_SYNC` 标志表示系统已检测到发动机位置并保持同步
- 只有同步状态下才允许燃油和点火控制
- 失去同步时会禁用燃油和点火，防止发动机损坏

## 5. 第三阶段：传感器数据处理与物理量转换

### 5.1 核心变量生成

**代码位置**: `src/coreVarsGenerator.c` - `generateCoreVars()`

系统将原始 ADC 值转换为物理量：

#### 5.1.1 MAP（歧管压力）转换

```c
/* 如果 MAP 传感器已连接 */
if(TRUE){
    /* 使用转换变量从 ADC 获取 MAP */
    // 线性转换：值 = (ADC值 * 范围) / ADC分辨率 + 最小值
    // 单位：kPa * 100（例如：10000 = 100.00 kPa）
    localMAP = (((unsigned long)ADCArrays->MAP * fixedConfigs2.sensorRanges.MAPRange) 
                / ADC_DIVISIONS) + fixedConfigs2.sensorRanges.MAPMinimum;
}
```

**转换示例**:
- ADC值 = 512（满量程的一半）
- MAPRange = 30000（300.00 kPa范围）
- MAPMinimum = 0（0.00 kPa最小值）
- MAP = (512 × 30000) / 1024 + 0 = 15,000 = 150.00 kPa

#### 5.1.2 TPS（节气门位置）转换

```c
/* 从 ADC 获取 TPS，不需要添加 TPS 最小值，因为我们知道根据定义它是零 */
// 将ADC值转换为百分比：值 = (ADC值 * 最大值) / ADC范围
localTPS = ((unsigned long)boundedTPSADC * TPS_RANGE_MAX) / TPSADCRange;
```

**转换示例**:
- boundedTPSADC = 512（校准后的ADC值）
- TPS_RANGE_MAX = 64000（100% = 64000/640）
- TPSADCRange = 512（ADC范围）
- TPS = (512 × 64000) / 512 = 64,000 = 100%

**双缓冲机制**:
- 计算使用一个缓冲区的数据（稳定快照）
- ISR 持续更新另一个缓冲区的数据
- 原子操作确保切换时数据一致性

### 6.2 燃油脉宽计算流程

虽然 `fuelAndIgnitionCalcs.c` 中的完整计算代码当前被注释，但根据代码注释和结构，计算流程如下：

#### 6.2.1 基础脉宽计算

```c
// 基础脉宽 = (燃油常数 * 空气流量) / 密度和燃油因子
BasePW = (FuelConstant * AirFlow) / densityAndFuel

其中:
FuelConstant = (masterFuelConstant / injectorFlow) * perCylinderVolume / stoichiometricAFR
AirFlow = MAP * VE / 100% (速度密度模式)
densityAndFuel = (IAT * Lambda / stoichiometricLambda) * fuelDensity / divisor
```

**物理意义**:
- **FuelConstant**: 根据喷油器流量、气缸容积和理论空燃比计算的常数
- **AirFlow**: 根据歧管压力和容积效率计算的空气流量
- **densityAndFuel**: 考虑进气温度和目标空燃比的密度修正

#### 6.2.2 修正应用

```c
// 应用瞬态燃油修正
EffectivePW = BasePW * (1 + TFC/100)

// 应用发动机温度修正
EffectivePW = EffectivePW * (1 + ETE/100)

// 添加喷油器死区时间
FinalPW = EffectivePW + IDT

// 应用每缸修正
ChannelPW = FinalPW * (1 + PerCylinderTrim[channel]/100)
```

**修正类型**:
- **TFC (Transient Fuel Correction)**: 瞬态燃油修正，响应快速变化的工况
- **ETE (Engine Temperature Enrichment)**: 发动机温度修正，冷启动时增加燃油
- **IDT (Injector Dead Time)**: 喷油器死区时间，最小开启时间
- **PCFC (Per Cylinder Fuel Correction)**: 每缸燃油修正，平衡各缸空燃比

## 7. 第五阶段：事件调度

### 7.1 喷油事件调度

**代码位置**: `src/Simple.c` 第 119-161 行

```c
if(masterPulseWidth > injectorMinimumPulseWidth){ 
    // 使用参考脉宽来决定。火花需要移出此区域 TODO
    
    /* 确定半个周期是否大于 short-max */
    unsigned short maxAngleAfter;
    if((engineCyclePeriod >> 1) > 0xFFFF){
        maxAngleAfter = 0xFFFF;
    }else{
        maxAngleAfter = (unsigned short)(engineCyclePeriod >> 1);
    }
    
    /* 检查提前角以确保它小于前一个发动机周期的 1/2 且大于代码时间 */
    unsigned short advance;
    if(totalAngleAfterReferenceInjection > maxAngleAfter){ 
        // 如果太大，使其为最大值
        advance = maxAngleAfter;
    }else if(totalAngleAfterReferenceInjection < trailingEdgeSecondaryRPMInputCodeTime){ 
        // 如果太小，使其为最小值
        advance = trailingEdgeSecondaryRPMInputCodeTime;
    }else{ 
        // 否则按原样使用
        advance = totalAngleAfterReferenceInjection;
    }
    
    // 确定长和短开始时间
    unsigned short startTime = edgeTimeStamp + advance;
    unsigned long startTimeLong = timeStamp.timeLong + advance;
    
    /* 确定要调度的通道 */
    unsigned char fuelChannel = 0;
    
    // 确定是否重新调度
    unsigned char reschedule = 0;
    unsigned long diff = startTimeLong - (injectorMainEndTimes[fuelChannel] + injectorSwitchOffCodeTime);
    if(diff > LONGHALF){
        reschedule = 1;
    }
    
    // 调度适当的通道
    if(!(*injectorMainControlRegisters[fuelChannel] & injectorMainEnableMasks[fuelChannel]) || reschedule){ 
        /* 如果定时器仍在运行，或者设置时间过长，将其设置为在正确的时间重新开始 */
        *injectorMainControlRegisters[fuelChannel] |= injectorMainEnableMasks[fuelChannel];
        *injectorMainTimeRegisters[fuelChannel] = startTime;
        TIE |= injectorMainOnMasks[fuelChannel];
        TFLG = injectorMainOnMasks[fuelChannel];
    }else{
        injectorMainStartTimesHolding[fuelChannel] = startTime;
        selfSetTimer |= injectorMainOnMasks[fuelChannel]; 
        // 设置一个位让定时器中断知道从变量设置自己的新开始
    }
}
```

**调度逻辑**:
1. **检查最小脉宽**: 只有脉宽大于最小值才调度
2. **计算提前角**: 确定喷油相对于参考点的提前角度
3. **边界检查**: 确保提前角在合理范围内
4. **计算开始时间**: `startTime = edgeTimeStamp + advance`
5. **检查重调度**: 如果时间间隔太长，需要重新调度
6. **设置定时器**: 配置输出比较寄存器在正确时间触发

**时序控制**:
- `edgeTimeStamp`: 当前曲轴位置的时间戳
- `advance`: 喷油提前角（定时器计数单位）
- `startTime`: 喷油器应该开启的绝对时间

### 7.2 调度示例

假设：
- 当前曲轴位置时间戳 = 100,000
- 喷油提前角 = 5,000（定时器计数）
- 开始时间 = 100,000 + 5,000 = 105,000

定时器会在计数达到 105,000 时触发中断，开启喷油器。

### 8.3 硬件控制

**代码位置**: `src/inc/injectorISR.c`

系统通过以下硬件寄存器控制喷油器：

```c
// 时间寄存器：设置输出比较的时间值
*injectorMainTimeRegisters[channel] = startTime;

// 控制寄存器：设置输出比较的动作（高电平/低电平）

```

**硬件工作原理**:
- 定时器的输出比较功能在指定时间自动改变输出引脚状态
- 无需 CPU 干预，实现精确的时序控制
- 中断用于处理边界情况和调度下次事件

## 9. 完整控制循环示例

### 9.1 一个完整的发动机循环

假设一个 4 缸发动机在 3000 RPM 运行：

**时间线**:

1. **T=0ms**: 曲轴位置传感器产生脉冲
   - `PrimaryRPMISR()` 被触发
   - 计算 RPM = 3000
   - 采样所有 ADC 通道
   - 设置 `CALC_FUEL_IGN` 标志

2. **T=0.1ms**: 主循环检测到计算标志
   - 切换输入缓冲区
   - 调用 `generateCoreVars()`
   - 转换传感器值：
     - MAP = 100 kPa
     - TPS = 50%
     - RPM = 3000
     - IAT = 30°C

3. **T=0.5ms**: 计算完成
   - 查找 VE 表：MAP=100kPa, RPM=3000 → VE=85%
   - 计算基础脉宽：BasePW = 2.5ms
   - 应用修正：FinalPW = 2.8ms
   - 存储到 `injectorMainPulseWidthsMath[0]`

4. **T=1.0ms**: 切换输出缓冲区
   - `injectorMainPulseWidthsRealtime[0] = 2.8ms`

5. **T=5.0ms**: 下一个曲轴脉冲
   - `PrimaryRPMISR()` 再次触发
   - 调度喷油事件：
     - `startTime = edgeTimeStamp + advance`
     - `advance = 5000` (定时器计数)
     - 设置定时器在 `startTime` 触发

6. **T=5.0ms + advance**: 定时器触发
   - `Injector1ISR()` 被调用
   - 开启喷油器（硬件自动控制）
   - 设置关闭时间：`关闭时间 = 当前时间 + 2.8ms`

7. **T=5.0ms + advance + 2.8ms**: 定时器再次触发
   - `Injector1ISR()` 再次被调用（下降沿）
   - 关闭喷油器（硬件自动控制）
   - 燃油已喷入气缸

8. **T=10.0ms**: 下一个循环开始
   - 重复上述过程

### 9.2 时序精度

**定时器分辨率**:
- 定时器频率 = 40MHz / 16 = 2.5MHz
- 每个计数 = 0.4μs
- 对于 2.8ms 的脉宽，精度 = 2.8ms / 0.4μs = 7,000 个计数

**实际精度**:
- 理论精度：±0.4μs
- 实际精度（考虑中断延迟）：±1-2μs
- 对于 3000 RPM，一个循环 = 20ms，精度 = 0.01%

## 10. 安全机制

### 10.1 同步丢失保护

**代码位置**: `src/MissingTeeth.c`, `src/NipponDenso.c`

```c

    /* 清除同步状态 */
    coreStatusA &= CLEAR_PRIMARY_SYNC;
    
    /* 重置齿计数 */
    primaryPulsesPerSecondaryPulse = 0;
    
    /* 在造成损害之前退出 */
    return;
}
```

**保护机制**:
- 如果检测到异常脉冲（同步丢失），清除同步标志
- 主循环检查同步状态，未同步时不执行计算
- 防止在错误时机喷油或点火，避免发动机损坏

## 12. 性能优化

### 12.1 双缓冲机制

**输入缓冲**:
- `ADCArrays0` 和 `ADCArrays1` 交替使用
- 计算使用一个缓冲区，ISR 更新另一个
- 避免数据竞争，确保计算使用稳定数据

**输出缓冲**:
- `injectorMainPulseWidths0` 和 `injectorMainPulseWidths1` 交替使用
- 计算写入一个缓冲区，ISR 读取另一个
- 避免计算过程中数据被修改

### 12.2 原子操作

**代码位置**: `src/main.c`

```c
ATOMIC_START(); /* 开始原子操作块，禁用中断 */
```

**作用**:
- 在切换缓冲区时禁用中断
- 确保切换操作的原子性
- 防止 ISR 在切换过程中访问错误的数据

- 确保延迟在可接受范围内

## 13. 实际行驶控制

### 13.1 加速控制

当驾驶员踩下油门踏板时：

1. **TPS 传感器检测**: TPS 值从 10% 增加到 80%
2. **MAP 传感器响应**: 节气门打开，MAP 增加
3. **计算响应**: 
   - 查找更高的 VE 值
   - 计算更大的基础脉宽
   - 应用瞬态修正（增加燃油）
4. **执行**: 喷油脉宽从 2.0ms 增加到 5.0ms
5. **结果**: 更多燃油 → 更多动力 → 发动机加速

### 13.2 减速控制

当驾驶员松开油门踏板时：

1. **TPS 传感器检测**: TPS 值从 80% 减少到 10%
2. **MAP 传感器响应**: 节气门关闭，MAP 降低
3. **计算响应**:
   - 查找更低的 VE 值
   - 计算更小的基础脉宽
   - 应用瞬态修正（减少燃油）
4. **执行**: 喷油脉宽从 5.0ms 减少到 1.5ms
5. **结果**: 更少燃油 → 更少动力 → 发动机减速

### 13.3 巡航控制

在稳定巡航时：

1. **传感器稳定**: TPS、MAP、RPM 保持相对稳定
2. **计算稳定**: 脉宽计算值在很小范围内波动
3. **执行稳定**: 喷油脉宽保持稳定
4. **结果**: 稳定的燃油供应 → 稳定的动力输出 → 稳定的车速

## 14. 总结

FreeMS2 通过以下机制控制汽车行驶：

1. **精确的位置检测**: 通过曲轴/凸轮轴位置传感器实时跟踪发动机位置
2. **全面的传感器采集**: 采集所有相关传感器数据
3. **智能的计算**: 根据传感器数据计算精确的燃油和点火参数
4. **精确的时序控制**: 使用硬件定时器在精确时刻控制执行器
5. **可靠的安全机制**: 多重保护确保系统安全运行
6. **高效的性能优化**: 双缓冲、原子操作等机制确保实时性

整个系统形成了一个完整的闭环控制：
- **输入**: 传感器数据
- **处理**: 计算和决策
- **输出**: 执行器控制
- **反馈**: 传感器持续监控

通过这个闭环系统，FreeMS2 能够精确控制发动机运行，实现汽车的加速、减速、巡航等各种行驶状态。
