## 1. 系统启动流程

### 1.1 硬件复位到程序入口

**执行顺序**：
```
硬件复位
  ↓
复位向量表（interrupts.c）
  ↓
启动代码（链接器生成）
  ↓
main() 函数（main.c:77）
```

**涉及文件**：
- **`interrupts.c`**：定义中断向量表，包含复位向量
- **`main.c`**：程序入口点

**代码位置**：
```c
// interrupts.c - 中断向量表定义
// 复位向量指向启动代码

// main.c:77 - 程序入口
int main(){
    init();  // 调用初始化函数
    while(TRUE){  // 进入主循环
        // ...
    }
}
```

### 1.2 启动代码的作用

启动代码（由链接器自动生成）负责：
1. **初始化栈指针**：设置堆栈
2. **清零BSS段**：将未初始化的全局变量清零
3. **复制DATA段**：将已初始化的全局变量从Flash复制到RAM
4. **调用main()**：跳转到用户代码

## 2. 初始化阶段

### 2.1 初始化流程概览

**执行顺序**（`main.c:79` → `init.c:65`）：
```
main()
  ↓
init() - 主初始化函数
  ├── initPLL() - 时钟初始化
  ├── initIO() - I/O初始化
  ├── initAllPagedRAM() - 内存初始化
  ├── initVariables() - 变量初始化
  ├── initFlash() - Flash初始化
  ├── initECTTimer() - 定时器初始化
  ├── initSCIStuff() - 串口初始化
  ├── initConfiguration() - 配置初始化
  └── initInterrupts() - 中断初始化（最后）
```

### 2.2 初始化详细流程

#### 阶段1：时钟初始化（`init.c:233`）

**功能**：设置系统时钟频率

**涉及文件**：
- **`init.c`**：`initPLL()` 函数

**执行内容**：
```c
void initPLL(){
    // 1. 切换到外部时钟
    // 2. 关闭PLL
    // 3. 设置分频和倍频参数
    // 4. 启动PLL并等待锁定
    // 5. 切换到PLL时钟源
}
```

**为什么最先执行**：
- 所有外设都依赖正确的时钟频率
- ADC采样时间、定时器频率都基于时钟

#### 阶段2：I/O初始化（`init.c:233`）

**功能**：配置所有I/O引脚为安全状态

**涉及文件**：
- **`init.c`**：`initIO()` 函数

**执行内容**：
```c
void initIO(){
    // 1. 配置端口方向（输入/输出）
    // 2. 设置初始值（避免意外操作）
    // 3. 配置上拉/下拉电阻
}
```

#### 阶段3：内存初始化（`init.c:439`）

**功能**：将查找表和配置数据从Flash复制到RAM

**涉及文件**：
- **`init.c`**：`initAllPagedRAM()` 函数
- **`FuelTables.c`**, **`TimingTables.c`** 等：表格数据源
- **`FixedConfig1.c`**, **`FixedConfig2.c`**：配置数据源
- **`TunableConfig.c`**, **`TunableConfig2.c`**：可调配置数据源

**执行内容**：
```c
void initAllPagedRAM(){
    // 1. 设置RPAGE寄存器指向查找表RAM页面
    // 2. 使用memcpy将Flash中的表格复制到RAM
    // 3. 重复上述步骤复制其他表格
}
```

**为什么需要**：
- RAM访问速度比Flash快
- 可以在运行时修改表格（实时调校）

#### 阶段4：变量初始化（`init.c:442`）

**功能**：初始化运行时变量

**涉及文件**：
- **`init.c`**：`initVariables()` 函数
- **`staticInit.c`**：静态初始化数据

**执行内容**：
```c
void initVariables(){
    // 1. 初始化计数器
    // 2. 初始化运行时变量
    // 3. 初始化状态标志
    // 4. 设置默认值
}
```

#### 阶段5：外设初始化

**定时器初始化**（`init.c:442`）：
- **`init.c`**：`initECTTimer()` 函数
- 配置ECT定时器用于发动机位置检测和喷油器控制

**串口初始化**（`init.c:442`）：
- **`init.c`**：`initSCIStuff()` 函数
- 配置串口用于通信

**Flash初始化**（`init.c:442`）：
- **`init.c`**：`initFlash()` 函数
- 配置Flash控制器

#### 阶段6：配置初始化（`init.c:442`）

**功能**：加载用户配置

**涉及文件**：
- **`init.c`**：`initConfiguration()` 函数
- **`FixedConfig1.c`**, **`FixedConfig2.c`**：固定配置
- **`TunableConfig.c`**, **`TunableConfig2.c`**：可调配置

#### 阶段7：中断初始化（`init.c:442`）

**功能**：配置并启用中断（最后执行）

**涉及文件**：
- **`init.c`**：`initInterrupts()` 函数
- **`interrupts.c`**：中断向量表

**执行内容**：
```c
void initInterrupts(){
    // 1. 配置中断优先级
    // 2. 设置中断向量
    // 3. 启用中断（最后一步）
}
```

**为什么最后执行**：
- 确保所有数据结构已初始化
- 避免ISR访问未初始化的数据

## 3. 主循环运行阶段

### 3.1 主循环结构

**执行位置**：`main.c:83` - `while(TRUE)` 循环

**主循环功能**：
1. **ADC强制采样处理**
2. **燃油和点火计算**
3. **通信数据包处理**
4. **其他非实时任务**

### 3.2 主循环详细流程

#### 功能1：ADC强制采样（`main.c:86`）

**触发条件**：`coreStatusA & FORCE_READING`

**涉及文件**：
- **`main.c`**：主循环代码
- **`utils.c`**：`sampleEachADC()` 函数

**执行流程**：
```c
if(coreStatusA & FORCE_READING){
    ATOMIC_START();
    sampleEachADC(ADCArraysRecord);  // utils.c
    resetToNonRunningState();
    coreStatusA |= CALC_FUEL_IGN;  // 设置计算标志
    coreStatusA &= CLEAR_FORCE_READING;
    ATOMIC_END();
}
```

**数据流**：
```
ADC硬件 → sampleEachADC() → ADCArraysRecord缓冲区
```

#### 功能2：燃油和点火计算（`main.c:112`）

**触发条件**：`coreStatusA & CALC_FUEL_IGN`

**涉及文件**：
- **`main.c`**：主循环和缓冲区切换
- **`coreVarsGenerator.c`**：`generateCoreVars()` - 核心变量生成
- **`derivedVarsGenerator.c`**：`generateDerivedVars()` - 派生变量生成
- **`fuelAndIgnitionCalcs.c`**：`calculateFuelAndIgnition()` - 燃油和点火计算
- **`tableLookup.c`**：查找表访问函数

**执行流程**：
```c
if(coreStatusA & CALC_FUEL_IGN){
    // 1. 切换输入缓冲区（原子操作）
    ATOMIC_START();
    if(ADCArrays == &ADCArrays1){
        ADCArrays = &ADCArrays0;  // 切换到计算缓冲区
        ADCArraysRecord = &ADCArrays1;  // ISR使用记录缓冲区
    }
    coreStatusA &= CLEAR_CALC_FUEL_IGN;
    ATOMIC_END();
    
    // 2. 生成核心变量
    generateCoreVars();  // coreVarsGenerator.c
    
    // 3. 生成派生变量
    generateDerivedVars();  // derivedVarsGenerator.c
    
    // 4. 计算燃油和点火
    calculateFuelAndIgnition();  // fuelAndIgnitionCalcs.c
    
    // 5. 切换输出缓冲区（原子操作）
    ATOMIC_START();
    // 切换喷油脉宽和点火提前角缓冲区
    ATOMIC_END();
}
```

**数据流**：
```
ADCArrays (输入)
  ↓
generateCoreVars() → CoreVars
  ↓
generateDerivedVars() → DerivedVars
  ↓
calculateFuelAndIgnition() → injectorMainPulseWidthsMath (输出)
```

**详细调用链**：

1. **`generateCoreVars()`**（`coreVarsGenerator.c:59`）：
   ```
   generateCoreVars()
     ├── 读取ADCArrays中的原始ADC值
     ├── 使用IATTransferTable.c转换IAT
     ├── 使用CHTTransferTable.c转换CHT
     ├── 使用MAFTransferTable.c转换MAF
     ├── 线性转换其他传感器（MAP、TPS等）
     └── 存储到CoreVars结构体
   ```

2. **`generateDerivedVars()`**（`derivedVarsGenerator.c:54`）：
   ```
   generateDerivedVars()
     ├── 计算LoadMain（负荷值）
     ├── 查找VETableMain（FuelTables.c）
     ├── 查找LambdaTable（FuelTables.c）
     ├── 查找IDT表（TunableConfig.c）
     ├── 查找ETE表（TunableConfig.c）
     └── 存储到DerivedVars结构体
   ```

3. **`calculateFuelAndIgnition()`**（`fuelAndIgnitionCalcs.c:64`）：
   ```
   calculateFuelAndIgnition()
     ├── 计算AirFlow（根据SpeedDensity/AlphaN/MAF方法）
     ├── 计算BasePW（基础脉宽）
     ├── 应用修正（TFC、ETE、PCFC、IDT）
     ├── 计算点火提前角（TimingTables.c）
     └── 存储到输出缓冲区
   ```

#### 功能3：通信处理（`main.c:195`）

**触发条件**：`RXStateFlags & RX_READY_TO_PROCESS`

**涉及文件**：
- **`main.c`**：主循环代码
- **`commsCore.c`**：`decodePacketAndRespond()` - 数据包解码和响应

**执行流程**：
```c
if(RXStateFlags & RX_READY_TO_PROCESS){
    RXStateFlags &= RX_CLEAR_READY_TO_PROCESS;
    decodePacketAndRespond();  // commsCore.c
}
```

**数据流**：
```
串口接收 → commsISRs.c (ISR) → RXBuffer → decodePacketAndRespond() → TXBuffer → 串口发送
```

## 4. 中断处理流程

### 4.1 中断系统架构

**中断优先级**（从高到低）：
1. **发动机位置中断**（最高优先级）
2. **喷油器控制中断**
3. **通信中断**
4. **实时中断**（最低优先级）

### 4.2 关键中断处理流程

#### 中断1：发动机位置检测（PrimaryRPMISR）

**触发源**：曲轴位置传感器信号

**涉及文件**：
- **`interrupts.c`**：中断向量表定义
- **`Simple.c`**, **`MissingTeeth.c`**, **`NipponDenso.c`** 等：位置解码器实现
- **`utils.c`**：`sampleEachADC()` - ADC采样函数

**执行流程**（以`Simple.c`为例）：
```c
void PrimaryRPMISR(void){
    // 1. 清除中断标志
    TFLG = 0x01;
    
    // 2. 记录时间戳
    unsigned short edgeTimeStamp = TC0;
    
    // 3. 计算RPM
    timeBetweenSuccessivePrimaryPulses = ...;
    *RPMRecord = ticksPerMinute / timeBetweenSuccessivePrimaryPulses;
    
    // 4. 采样ADC（在特定齿位置）
    sampleEachADC(ADCArraysRecord);  // utils.c
    
    // 5. 设置计算标志
    coreStatusA |= CALC_FUEL_IGN;  // 通知主循环需要计算
}
```

**数据流**：
```
曲轴信号 → 硬件捕获 → PrimaryRPMISR() → 
  ├── 计算RPM → RPMRecord
  ├── 采样ADC → ADCArraysRecord
  └── 设置标志 → coreStatusA |= CALC_FUEL_IGN
```

**文件调用关系**：
```
Simple.c (PrimaryRPMISR)
  ↓
utils.c (sampleEachADC)
  ↓
ADC硬件读取
```

#### 中断2：喷油器控制（InjectorXISR）

**触发源**：定时器输出比较匹配

**涉及文件**：
- **`interrupts.c`**：中断向量表定义
- **`injectionISRs.c`**：喷油器ISR入口
- **`inc/injectorISR.c`**：共享的喷油器ISR代码

**执行流程**（`injectorISR.c:59`）：
```c
void InjectorXISR(){
    // 1. 清除中断标志
    TFLG = injectorMainOnMasks[channel];
    
    // 2. 判断是开启还是关闭事件
    if(PTIT & injectorMainOnMasks[channel]){  // 开启事件
        // 读取脉宽
        unsigned short localPulseWidth = injectorMainPulseWidthsRealtime[channel];
        
        // 设置关闭时间
        *injectorMainTimeRegisters[channel] += localPulseWidth;
        *injectorMainControlRegisters[channel] &= injectorMainGoLowMasks[channel];
    }else{  // 关闭事件
        // 关闭喷油器
        // 调度下次开启或禁用通道
    }
}
```

**数据流**：
```
主循环计算 → injectorMainPulseWidthsMath → 缓冲区切换 → 
injectorMainPulseWidthsRealtime → InjectorXISR() → 硬件输出
```

**文件调用关系**：
```
main.c (计算脉宽)
  ↓
injectorMainPulseWidthsRealtime (输出缓冲区)
  ↓
InjectorXISR() (injectorISR.c)
  ↓
硬件定时器输出
```

#### 中断3：串口通信（SCI0ISR）

**触发源**：串口接收/发送数据就绪

**涉及文件**：
- **`interrupts.c`**：中断向量表定义
- **`commsISRs.c`**：`SCI0ISR()` - 串口中断处理

**执行流程**（`commsISRs.c:186`）：
```c
void SCI0ISR(){
    // 1. 读取状态寄存器
    unsigned char flags = SCI0SR1;
    
    // 2. 处理接收
    if(flags & SCISR1_RX_REGISTER_FULL){
        unsigned char rawByte = SCI0DRL;
        // 处理数据包（转义、校验和等）
        // 存储到RXBuffer
        if(数据包完整){
            RXStateFlags |= RX_READY_TO_PROCESS;  // 通知主循环
        }
    }
    
    // 3. 处理发送
    if(flags & SCISR1_TX_REGISTER_EMPTY){
        // 从TXBuffer发送下一个字节
    }
}
```

**数据流**：
```
串口硬件 → SCI0ISR() → RXBuffer → 主循环处理 → TXBuffer → SCI0ISR() → 串口硬件
```

#### 中断4：实时中断（RTIISR）

**触发源**：实时时钟定时器

**涉及文件**：
- **`interrupts.c`**：中断向量表定义
- **`realtimeISRs.c`**：`RTIISR()` - 实时中断处理

**执行流程**（`realtimeISRs.c:55`）：
```c
void RTIISR(){
    // 1. 清除中断标志
    CRGFLG = 0x80;
    
    // 2. 更新系统时钟
    timerExtensionClock++;
    
    // 3. 检查超时
    if(超时){
        coreStatusA |= FORCE_READING;  // 强制ADC采样
    }
}
```

## 5. 数据流与文件协作

### 5.1 输入数据流

**数据流向**：
```
传感器硬件
  ↓
ADC硬件（自动采样）
  ↓
PrimaryRPMISR() (位置解码器文件)
  ├── sampleEachADC() (utils.c)
  └── ADCArraysRecord (输入缓冲区)
  ↓
主循环切换缓冲区 (main.c)
  ↓
ADCArrays (计算缓冲区)
  ↓
generateCoreVars() (coreVarsGenerator.c)
  ├── IATTransferTable.c (温度转换)
  ├── CHTTransferTable.c (温度转换)
  ├── MAFTransferTable.c (流量转换)
  └── CoreVars (核心变量结构体)
```

**涉及文件**：
- **位置解码器文件**（`Simple.c`等）：触发ADC采样
- **`utils.c`**：`sampleEachADC()` - ADC采样函数
- **`coreVarsGenerator.c`**：`generateCoreVars()` - 核心变量生成
- **转换表文件**（`IATTransferTable.c`等）：传感器数据转换

### 5.2 计算数据流

**数据流向**：
```
CoreVars (核心变量)
  ↓
generateDerivedVars() (derivedVarsGenerator.c)
  ├── lookupPagedMainTableCellValue() (tableLookup.c)
  ├── FuelTables.c (VE表查找)
  ├── FuelTables.c (Lambda表查找)
  ├── TunableConfig.c (IDT、ETE等表查找)
  └── DerivedVars (派生变量结构体)
  ↓
calculateFuelAndIgnition() (fuelAndIgnitionCalcs.c)
  ├── 使用DerivedVars计算
  └── injectorMainPulseWidthsMath (输出缓冲区)
```

**涉及文件**：
- **`derivedVarsGenerator.c`**：派生变量生成
- **`tableLookup.c`**：查找表访问函数
- **`FuelTables.c`**：VE表和Lambda表
- **`TimingTables.c`**：点火提前角表
- **`TunableConfig.c`**：可调配置表
- **`fuelAndIgnitionCalcs.c`**：燃油和点火计算

### 5.3 输出数据流

**数据流向**：
```
injectorMainPulseWidthsMath (计算缓冲区)
  ↓
主循环切换缓冲区 (main.c)
  ↓
injectorMainPulseWidthsRealtime (实时缓冲区)
  ↓
InjectorXISR() (injectorISR.c)
  ↓
硬件定时器输出
  ↓
喷油器硬件
```

**涉及文件**：
- **`main.c`**：缓冲区切换
- **`injectorISR.c`**：喷油器ISR
- **`injectionISRs.c`**：ISR入口

### 5.4 配置数据流

**数据流向**：
```
Flash存储
  ├── FixedConfig1.c (固定配置1)
  ├── FixedConfig2.c (固定配置2)
  ├── TunableConfig.c (可调配置1)
  ├── TunableConfig2.c (可调配置2)
  ├── FuelTables.c (燃油表)
  ├── TimingTables.c (时序表)
  └── 转换表文件 (IATTransferTable.c等)
  ↓
initAllPagedRAM() (init.c)
  ↓
RAM副本（运行时访问）
  ↓
运行时使用（tableLookup.c等）
```

**涉及文件**：
- **配置文件**（`FixedConfig1.c`等）：配置数据定义
- **表格文件**（`FuelTables.c`等）：查找表数据定义
- **`init.c`**：`initAllPagedRAM()` - 内存初始化
- **`tableLookup.c`**：查找表访问函数

## 7. 关键执行路径

### 7.1 路径1：发动机启动到第一次喷油

**执行路径**：
```

   ↓
2. main() → init()
   ├─ initPLL() - 设置时钟
   ├─ initIO() - 配置I/O
   ├─ initAllPagedRAM() - 复制表格到RAM
   ├─ initECTTimer() - 配置定时器
   ├─ initInterrupts() - 启用中断
   └─ 返回main()
   ↓
3. 进入主循环 while(TRUE)
   ↓
4. 等待曲轴信号
   ↓
5. PrimaryRPMISR() 触发
   ├─ 计算RPM
   ├─ sampleEachADC() - 采样传感器
   └─ coreStatusA |= CALC_FUEL_IGN
   ↓

   ├─ 切换输入缓冲区

   ├─ generateDerivedVars() - 生成派生变量

   ↓

```

### 7.2 路径2：通信数据包处理

**执行路径**：
```
1. 串口接收到数据
   ↓
2. SCI0ISR() 触发（接收中断）
```

**涉及文件**：

## 9. 关键设计模式

### 9.1 事件驱动模式

**实现方式**：
- ISR设置标志位（事件发生）
- 主循环检查标志位（事件处理）

**代码体现**：
```c
// ISR中
coreStatusA |= CALC_FUEL_IGN;  // 设置事件标志

// 主循环中
if(coreStatusA & CALC_FUEL_IGN){  // 检查事件标志
    // 处理事件
}
```

### 9.2 双缓冲模式

**实现方式**：
- 输入：ISR写入缓冲区A，主循环读取缓冲区B
- 输出：主循环写入缓冲区A，ISR读取缓冲区B
- 通过指针切换实现缓冲区交换

**代码体现**：
```c
// 输入缓冲区切换
if(ADCArrays == &ADCArrays1){
    ADCArrays = &ADCArrays0;  // 切换到计算缓冲区
    ADCArraysRecord = &ADCArrays1;  // ISR使用记录缓冲区
}

// 输出缓冲区切换
if(injectorMainPulseWidthsMath == injectorMainPulseWidths1){
    injectorMainPulseWidthsMath = injectorMainPulseWidths0;
    injectorMainPulseWidthsRealtime = injectorMainPulseWidths1;
}
```

### 9.3 模板方法模式

**实现方式**：
- 通过宏定义和`#include`实现代码复用
- 喷油器ISR代码在所有通道间共享

**代码体现**：
```c
// injectionISRs.c
#define INJECTOR_CHANNEL_NUMBER 0
#define InjectorXISR Injector1ISR
#include "inc/injectorISR.c"
```

### 9.4 策略模式

**实现方式**：
- 不同位置解码器实现相同的接口
- 编译时选择解码器

**代码体现**：
```c
// 所有解码器都实现相同的函数签名
void PrimaryRPMISR(void);
void SecondaryRPMISR(void);
```

## 10. 总结

### 10.1 执行流程总结

1. **启动阶段**：硬件复位 → 启动代码 → `main()`
2. **初始化阶段**：`init()` → 配置所有硬件和软件组件
3. **运行阶段**：
   - **主循环**：处理非实时任务（计算、通信）
   - **中断处理**：处理实时任务（位置检测、喷油控制、通信收发）

### 10.2 文件协作总结

- **数据定义文件**（Config、Table）：提供配置和查找表数据
- **初始化文件**（init.c）：将数据从Flash复制到RAM，配置硬件
- **计算文件**（coreVarsGenerator.c等）：处理传感器数据，计算控制输出
- **中断文件**（各种ISR）：实时处理硬件事件
- **工具文件**（utils.c等）：提供通用功能函数
- **主控制文件**（main.c）：协调所有模块的执行

### 10.3 关键设计原则

1. **实时性**：ISR处理实时任务，主循环处理非实时任务
2. **数据一致性**：通过双缓冲机制确保数据一致性
3. **模块化**：功能模块化，便于维护和扩展
4. **事件驱动**：基于事件触发，而非固定周期
5. **代码复用**：通过模板方法模式减少代码重复
