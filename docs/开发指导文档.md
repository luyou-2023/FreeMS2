# FreeMS2 开发指导文档

## 1. 开发环境搭建

### 1.1 工具链要求

#### 1.1.1 必需工具

- **交叉编译器**: m68hc11-gcc (GCC for Motorola 68HC11/68HC12)
- **链接器**: m68hc11-ld
- **目标文件工具**: m68hc11-objcopy, m68hc11-objdump
- **Make**: GNU Make
- **Git**: 版本控制

#### 1.1.2 可选工具

- **Doxygen**: 文档生成
- **调试器**: 支持 MC9S12 的调试器
- **串口工具**: 用于通信测试（如 minicom, screen）

#### 1.1.3 安装工具链

**Linux (Debian/Ubuntu)**:
```bash
sudo apt-get install gcc-m68hc1x binutils-m68hc1x
```

**macOS**:
```bash
# 使用 Homebrew 或从源码编译
brew install m68hc11-elf-gcc
```

**Windows**:
- 下载预编译的工具链
- 或使用 WSL (Windows Subsystem for Linux)

### 1.2 开发环境配置

#### 1.2.1 检查工具链

```bash
m68hc11-gcc --version
m68hc11-objcopy --version
make --version
```

#### 1.2.2 环境变量

确保工具链在 PATH 中：
```bash
export PATH=/usr/local/m68hc11/bin:$PATH
```

### 1.3 编辑器配置

推荐使用支持 C 语言的编辑器：

- **VSCode**: 安装 C/C++ 扩展
- **Eclipse**: 安装 CDT 插件
- **Vim/Emacs**: 配置 C 语言支持

## 3. 编译系统

### 3.1 Makefile 概述

项目使用 GNU Make 进行构建。Makefile 支持：

- 多阶段编译（预处理 → 汇编 → 链接）
- 多种构建目标
- 调试信息生成
- 内存使用统计

### 3.2 常用构建命令

#### 3.2.1 基本构建

```bash
# 创建必要的目录
make dirs

# 快速编译（单阶段）
make fast

# 完整编译（多阶段，保留中间文件）
make slow

# 完整编译（带垃圾回收）
make slowgc

# 完整构建（包括调试信息）
make all
```

#### 3.2.2 调试构建

```bash
# 生成所有调试信息
make alldebug

# 生成内存映射
make maps

# 生成反汇编
make elfdmps

# 生成对象文件反汇编
make objdmps
```

#### 3.2.3 清理

```bash
# 清理所有生成文件
make clean

# 清理特定类型
make cleanasm    # 清理汇编文件
make cleanobj    # 清理对象文件
make cleanout    # 清理输出文件
make cleans19    # 清理固件文件
```

### 3.3 构建流程

#### 3.3.1 标准构建流程

```
源代码 (.c)
    ↓
预处理 (.pp.c)
    ↓
编译 (.s)
    ↓
汇编 (.o)
    ↓
链接 (.elf)
    ↓
转换 (.s19)
```

#### 3.3.2 多解码器构建

系统为每个解码器生成独立的固件：

- `FreeMS2-Simple.s19`
- `FreeMS2-MissingTeeth.s19`
- `FreeMS2-NipponDenso.s19`
- `FreeMS2-Subaru-36-2-2-2.s19`
- `FreeMS2-MiataNB.s19`

### 3.4 编译选项

#### 3.4.1 GCC 选项

```makefile
GCCOPTS = -g -Wall -Werror -Winline -O \
          -m68hcs12 -mshort -ffunction-sections \
          -fomit-frame-pointer -msoft-reg-count=8 \
          -mauto-incdec -fsigned-char
```

- `-g`: 生成调试信息
- `-Wall`: 启用所有警告
- `-Werror`: 将警告视为错误
- `-O`: 优化
- `-m68hcs12`: 目标架构
- `-mshort`: 16 位 int
- `-ffunction-sections`: 函数分段（支持垃圾回收）

#### 3.4.2 链接选项

```makefile
LINKOPTS = -no-warn-mismatch \
           -defsym,vectors_addr=0xF780 \
           -m,m68hc12elfb \
           -T,hc9s12c128elfb.x
```

### 3.5 内存布局

内存布局在以下文件中定义：

- **memory.x**: 链接器脚本
- **regions.x**: 区域定义
- **hc9s12c128elfb.x**: 目标特定脚本

## 4. 添加新功能

### 4.1 添加新传感器

#### 4.1.1 步骤

1. **在 ADCArray 中添加字段** (`inc/structs.h`):
```c
typedef struct {
    // ... 现有字段
    unsigned short NewSensor;
} ADCArray;
```

2. **在 CoreVar 中添加字段** (`inc/structs.h`):
```c
typedef struct {
    // ... 现有字段
    unsigned short NewSensor;
} CoreVar;
```

3. **在 generateCoreVars() 中添加转换** (`coreVarsGenerator.c`):
```c
void generateCoreVars() {
    // ... 现有代码
    
    unsigned short localNewSensor;
    if (TRUE) { // 如果传感器连接
        localNewSensor = NewSensorTransferTable[ADCArrays->NewSensor];
    } else {
        localNewSensor = defaultValue;
    }
    
    CoreVars->NewSensor = localNewSensor;
}
```

4. **添加转换表** (创建 `NewSensorTransferTable.c`):
```c
const unsigned short NewSensorTransferTable[1024] = {
    // 转换表数据
};
```

5. **更新 Makefile**:
```makefile
LOOKUPCLASSES2 = MAFTransferTable.c TestTransferTable.c NewSensorTransferTable.c
```

### 4.2 添加新解码器

#### 4.2.1 步骤

1. **创建解码器文件** (`src/NewDecoder.c`):
```c
#include "inc/FreeMS2.h"
#include "inc/interrupts.h"
#include "inc/decoderInterface.h"

void PrimaryRPMISR(void) {
    // 清除中断标志
    TFLG = 0x01;
    
    // 保存时间戳
    unsigned short edgeTimeStamp = TC0;
    
    // 计算 RPM
    // ...
    
    // 触发 ADC 采样
    sampleEachADC(ADCArrays);
    
    // 设置计算标志
    coreStatusA |= CALC_FUEL_IGN;
}

void SecondaryRPMISR(void) {
    // 如果支持次输入
    TFLG = 0x02;
    // ...
}
```

2. **创建头文件** (`src/inc/NewDecoder.h`):
```c
#ifndef FILE_NewDecoder_H_SEEN
#define FILE_NewDecoder_H_SEEN
// 解码器特定定义
#endif
```

3. **更新 Makefile**:
```makefile
RPMCLASSES = Simple.c NipponDenso.c ... NewDecoder.c
RPMH = Simple.h NipponDenso.h ... NewDecoder.h
```

4. **实现解码逻辑**:
   - 检测同步
   - 计算 RPM
   - 触发 ADC 采样
   - 设置计算标志

### 4.3 添加新修正

#### 4.3.1 步骤

1. **在 DerivedVar 中添加字段** (`inc/structs.h`):
```c
typedef struct {
    // ... 现有字段
    unsigned short NewCorrection;
```

2. **在计算中应用修正** (`fuelAndIgnitionCalcs.c`):

```c
void calculateFuelAndIgnition() {
```

### 5.4 常见问题

#### 5.4.1 编译错误

**问题**: 未定义的引用
```
undefined reference to `function_name'
```

**解决**: 
- 检查函数是否在正确的文件中定义
- 检查 Makefile 是否包含源文件
- 检查函数声明和定义是否匹配

**问题**: 内存溢出
```
region text overflowed
```

**解决**:
- 使用 `make slowgc` 启用垃圾回收
- 优化代码大小
- 将代码移到分页内存

#### 5.4.2 运行时问题

**问题**: 同步丢失
- 检查传感器连接
- 检查解码器配置
- 检查中断优先级

**问题**: 计算不正确
- 检查传感器值
- 检查表格数据
- 检查计算逻辑

## 6. 代码规范

### 6.1 命名规范

#### 6.1.1 变量命名

- **全局变量**: 首字母大写，驼峰命名
  ```c
  unsigned short CoreVars;
  ADCArray* ADCArrays;
  ```

- **局部变量**: 小写，下划线分隔
  ```c
  unsigned short local_rpm;
  unsigned char channel_index;
  ```

- **常量**: 全大写，下划线分隔
  ```c
  #define MAX_RPM 8000
  #define ADC_DIVISIONS 1024
  ```

#### 6.1.2 函数命名

- **函数名**: 小写，动词开头
  ```c
  void generateCoreVars(void);
  unsigned short lookupTable(mainTable* table, unsigned short rpm);
  ```

#### 6.1.3 类型命名

- **结构体**: 首字母大写，驼峰命名
  ```c
  typedef struct {
      // ...
  } CoreVar;
  ```

### 6.2 代码风格

#### 6.2.1 缩进

使用 1 个 Tab 或 4 个空格（保持一致）。

#### 6.2.2 注释

```c
/** @brief 函数简要说明
 *
 * 详细描述函数的功能、参数、返回值等。
 *
 * @param param1 参数1说明
 * @param param2 参数2说明
 * @return 返回值说明
 *
 * @author 作者名
 * @todo TODO 待办事项
 */
```

#### 6.2.3 代码组织

- 每个文件开头有文件头注释
- 函数之间有空行分隔
- 相关代码组织在一起
- 使用 `#ifdef` 保护头文件

### 6.3 最佳实践

#### 6.3.1 中断处理

- 中断中只做必要工作
- 避免在中断中调用复杂函数
- 使用标志位与主循环通信
- 保护共享数据

#### 6.3.2 内存管理

- 避免动态内存分配
- 使用静态数组
- 注意分页内存访问
- 保护关键数据结构

#### 6.3.3 错误处理

- 检查所有输入
- 使用默认值处理错误
- 记录错误计数器
- 通过通信接口报告错误

## 8. 版本控制

### 8.1 Git 工作流

#### 8.1.1 分支策略

- **master**: 稳定版本
- **develop**: 开发分支
- **feature/**: 功能分支
- **bugfix/**: 修复分支

#### 8.1.2 提交规范

提交信息格式：
```
类型(范围): 简短描述

详细描述（可选）

- 变更点1
- 变更点2
```

类型：
- `feat`: 新功能
- `fix`: 修复
- `docs`: 文档
- `style`: 格式
- `refactor`: 重构
- `test`: 测试
- `chore`: 构建/工具

### 8.2 发布流程

#### 8.2.1 准备发布

```bash
# 1. 更新版本号 (Makefile)
VERSION = 0.1.0

# 2. 更新文档

# 3. 运行完整测试
make clean
make all

# 4. 检查 Git 状态
git status
```

#### 8.2.2 执行发布

```bash
# 执行发布构建
make release

# 这会：
# - 检查 Git 状态
# - 清理旧文件
# - 构建所有版本
# - 生成文档
# - 创建发布包
# - 提交并打标签
```
