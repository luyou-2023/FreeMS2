# FreeMS2 硬件运行机制文档

## 1. 引言

本文档详细说明 FreeMS2 固件如何在 MC9S12C128 微控制器硬件上运行，包括启动流程、内存映射、中断系统、硬件寄存器操作等底层机制。

## 2. 硬件平台概述

### 2.1 MC9S12C128 微控制器

**关键特性**:
- **CPU**: 16位 HCS12 内核
- **时钟**: 最高 80MHz (PLL)，总线频率 40MHz
- **Flash**: 128KB 分页 Flash 存储器
- **RAM**: 8KB 线性 RAM
- **定时器**: ECT (Enhanced Capture Timer) 模块，8个通道
- **ADC**: ATD0 模块，8通道，10位分辨率
- **串口**: SCI0 (Serial Communication Interface)
- **PWM**: 7通道 PWM 模块

### 2.2 内存架构

MC9S12C128 使用**分页内存架构**扩展地址空间：

```
线性地址空间 (64KB):
├── 0x0000 - 0x03FF: 寄存器空间
├── 0x0400 - 0x3FFF: 线性 Flash (14KB)
├── 0x4000 - 0x7FFF: 分页窗口 (16KB)
├── 0x8000 - 0xBFFF: 分页窗口 (16KB)
├── 0xC000 - 0xFFFF: 线性 Flash (16KB)
└── 0xFF00 - 0xFFFF: 中断向量表

分页地址空间 (扩展):
├── 0x3F0000 - 0x3F3FFF: PPAGE 0x38 (16KB)
├── 0x3F4000 - 0x3F5FFF: PPAGE 0x39 (8KB)
├── 0x3F8000 - 0x3F9FFF: PPAGE 0x3A (8KB)
└── ... (更多分页)
```

**分页机制**:
- 通过 `PPAGE` 寄存器 (地址 0x0030) 选择当前页面
- 分页窗口 (0x4000-0xBFFF) 映射到选中的页面
- 线性空间 (0x0400-0x3FFF, 0xC000-0xFFFF) 始终可用

## 3. 启动流程

### 3.1 复位序列

**代码位置**: `src/interrupts.c` 第 86 行

当硬件复位时，CPU 执行以下步骤：

1. **读取复位向量** (地址 0xFFFE-0xFFFF)
   ```c
   // 中断向量表最后一项是 _start
   const interruptTable _vectors[] VECTORS = {
       // ...
       _start  // 0xFFFF: 系统复位向量
   };
   ```

2. **跳转到 _start**
   - `_start` 是程序的入口点
   - 由链接器脚本定义 (`ENTRY(_start)`)

3. **C 运行时初始化**
   - 初始化 `.data` 段（从 Flash 复制到 RAM）
   - 清零 `.bss` 段
   - 设置栈指针 (`_stack = 0x4000-1`)

4. **调用 main()**
   ```c
   int main(){
       init();  // 初始化所有硬件
       while(TRUE){
           // 主循环
       }
   }
   ```

### 3.2 初始化流程

**代码位置**: `src/init.c` - `init()`

```c
void init(){
    ATOMIC_START();          // 1. 禁用所有中断
    initPLL();               // 2. 配置系统时钟
    initIO();                // 3. 配置 I/O 端口
    initAllPagedRAM();       // 4. 复制 Flash 到 RAM
    initVariables();         // 5. 初始化变量
    initFlash();             // 6. 配置 Flash 模块
    initECTTimer();          // 7. 配置定时器
    initSCIStuff();          // 8. 配置串口
    initConfiguration();     // 9. 验证配置
    initInterrupts();        // 10. 启用中断
    ATOMIC_END();            // 11. 重新启用中断
}
```

**初始化顺序的重要性**:
- **先禁用中断**: 防止初始化过程中被中断打断
- **先配置时钟**: 其他模块依赖正确的时钟频率
- **最后启用中断**: 确保所有硬件已正确配置

## 4. 内存映射详解

### 4.1 链接器脚本

**代码位置**: `src/memory.x`, `src/regions.x`, `src/hc9s12c128elfb.x`

链接器脚本定义了内存布局：

```ld
MEMORY {
    /* RAM 区域 */
    rxbuf    (rw) : ORIGIN = 0x3000, LENGTH = 0x0420  /* 接收缓冲区 */
    data     (rw) : ORIGIN = 0x3420, LENGTH = 0x0BE0  /* 通用 RAM */
    
    /* Flash 区域 */
    text1    (rx) : ORIGIN = 0x4000, LENGTH = 0x3800  /* 线性 Flash 1 */
    fixedconf1 (rx) : ORIGIN = 0x7800, LENGTH = 0x0400  /* 固定配置 1 */
    fixedconf2 (rx) : ORIGIN = 0x7C00, LENGTH = 0x0400  /* 固定配置 2 */
    text     (rx) : ORIGIN = 0xC000, LENGTH = 0x3780  /* 线性 Flash 2 */
    
    /* 分页 Flash */
    ppage38  (rx) : ORIGIN = 0x3F0000, LENGTH = 0x4000
    fpage39  (rx) : ORIGIN = 0x3F4000, LENGTH = 0x2000
    dpage39  (rx) : ORIGIN = 0x3F6000, LENGTH = 0x2000
    fpage3A  (rx) : ORIGIN = 0x3F8000, LENGTH = 0x2000
    dpage3A  (rx) : ORIGIN = 0x3FA000, LENGTH = 0x2000
    // ... 更多页面
}
```

### 4.2 代码段映射

**代码位置**: `src/regions.x`

```ld
SECTIONS {
    .text1  : { *(.text1) }  > text1      /* 初始化代码 */
    .fixedconf1 : { *(.fixedconf1) } > fixedconf1  /* 固定配置 1 */
    .fixedconf2 : { *(.fixedconf2) } > fixedconf2  /* 固定配置 2 */
    .text   : { *(.text) }   > text       /* 主程序代码 */
    .data   : { *(.data) }   > data       /* 初始化数据 */
    .bss    : { *(.bss) }    > data       /* 未初始化数据 */
    .vectors: { *(.vectors) } > text      /* 中断向量表 */
}
```

### 4.3 栈和堆

**栈指针**: `_stack = 0x4000-1`
- 栈从 RAM 顶部向下增长
- 位于 0x4000 之前（RAM 结束位置）

**堆**: 未显式定义
- 使用静态分配，无动态内存分配

## 5. 中断系统

### 5.1 中断向量表

**代码位置**: `src/interrupts.c` 第 48-89 行

中断向量表位于 Flash 末尾 (0xFF00-0xFFFF)：

```c
const interruptTable _vectors[] VECTORS = {
    // 0xFFE0 - 0xFFE7: ECT 定时器中断
    Injector6ISR,      // ECT7 (0xFFE0)
    Injector5ISR,      // ECT6 (0xFFE1)
    SecondaryRPMISR,   // ECT5 (0xFFE2)
    Injector4ISR,      // ECT4 (0xFFE3)
    Injector3ISR,      // ECT3 (0xFFE4)
    Injector2ISR,      // ECT2 (0xFFE5)
    Injector1ISR,      // ECT1 (0xFFE6)
    PrimaryRPMISR,     // ECT0 (0xFFE7)
    
    // 0xFFD0 - 0xFFDF: 外设中断
    SCI0ISR,           // SCI0 (0xFFD4)
    TimerOverflow,    // ECT 溢出 (0xFFDF)
    
    // 0xFFF0 - 0xFFFF: 系统中断
    RTIISR,           // 实时中断 (0xFFF0)
    IRQISR,           // IRQ (0xFFF1)
    XIRQISR,          // XIRQ (0xFFF2)
    _start            // 复位向量 (0xFFFF)
};
```

**向量表结构**:
- 每个向量占用 2 字节（函数地址）
- 向量地址 = 0xFF00 + 中断号
- 硬件自动跳转到对应地址

### 5.2 中断处理流程

**硬件流程**:
1. **中断发生**: 硬件模块设置中断标志
2. **CPU 响应**: CPU 完成当前指令
3. **保存上下文**: 自动保存 PC, CCR, A, B, X, Y, SP
4. **查找向量**: 根据中断号查找向量表
5. **跳转 ISR**: 跳转到对应的 ISR 函数
6. **执行 ISR**: 执行中断服务程序
7. **返回**: `RTI` 指令恢复上下文

**代码示例**:
```c
// ISR 函数声明（使用 __attribute__((interrupt))）
void PrimaryRPMISR(void) INT TEXT1;

// ISR 实现
void PrimaryRPMISR(){
    TFLG = 0x01;  // 清除中断标志
    // ... 处理代码 ...
    // 隐式 RTI 返回
}
```

### 5.3 中断优先级

**硬件优先级** (从高到低):
1. **复位** (0xFFFF): 最高优先级
2. **XIRQ** (0xFFF2): 不可屏蔽中断
3. **IRQ** (0xFFF1): 可屏蔽中断
4. **定时器中断** (0xFFE0-0xFFE7): 高优先级
5. **串口中断** (0xFFD4): 中等优先级
6. **RTI** (0xFFF0): 低优先级

**软件优先级控制**:
- `HPRIO` 寄存器可以调整中断优先级
- 当前代码未使用软件优先级调整

### 5.4 原子操作

**代码位置**: `src/inc/interrupts.h` 第 60-61 行

```c
#define ATOMIC_START() __asm__ __volatile__ ("sei")  // 禁用中断
#define ATOMIC_END()   __asm__ __volatile__ ("cli")  // 启用中断
```

**使用场景**:
- 切换双缓冲区时
- 修改共享标志时
- 访问关键数据结构时

**注意事项**:
- 原子操作块要尽可能短
- 避免在原子块中调用复杂函数
- 防止死锁

## 6. 硬件寄存器访问

### 6.1 寄存器定义

**代码位置**: `src/inc/9S12C128.h`

寄存器通过宏定义访问：

```c
/* 定义寄存器访问宏 */
#define DVUCP(address) (*((volatile unsigned char*)(address)))
#define DVUSP(address) (*((volatile unsigned short*)(address)))

/* 端口寄存器 */
#define PORTA DVUCP(0x0000)  // 端口 A 数据寄存器
#define PORTB DVUCP(0x0001)  // 端口 B 数据寄存器
#define DDRA  DVUCP(0x0002)  // 端口 A 方向寄存器

/* 定时器寄存器 */
#define TCNT  DVUSP(0x0044)  // 定时器计数器（16位）
#define TSCR1 DVUCP(0x0046)  // 定时器控制寄存器 1
#define TSCR2 DVUCP(0x004D)  // 定时器控制寄存器 2
#define TIE   DVUCP(0x004C)  // 定时器中断使能寄存器
#define TFLG  DVUCP(0x004E)  // 定时器标志寄存器
#define TC0   DVUSP(0x0050)  // 定时器通道 0（16位）
#define TC1   DVUSP(0x0052)  // 定时器通道 1（16位）
// ... TC2-TC7

/* ADC 寄存器 */
#define ATD0CTL2 DVUCP(0x0082)  // ADC 控制寄存器 2
#define ATD0CTL3 DVUCP(0x0083)  // ADC 控制寄存器 3
#define ATD0CTL4 DVUCP(0x0084)  // ADC 控制寄存器 4
#define ATD0CTL5 DVUCP(0x0085)  // ADC 控制寄存器 5
#define ATD0DR0  DVUSP(0x0090)  // ADC 数据寄存器 0（16位）
#define ATD0DR1  DVUSP(0x0092)  // ADC 数据寄存器 1（16位）
// ... ATD0DR2-ATD0DR7

/* 串口寄存器 */
#define SCI0BD   DVUSP(0x00C8)  // SCI 波特率寄存器（16位）
#define SCI0CR1  DVUCP(0x00CA)  // SCI 控制寄存器 1
#define SCI0CR2  DVUCP(0x00CB)  // SCI 控制寄存器 2
#define SCI0SR1  DVUCP(0x00CC)  // SCI 状态寄存器 1
#define SCI0DRL  DVUCP(0x00CF)  // SCI 数据寄存器（低字节）

/* PLL 寄存器 */
#define SYNR    DVUCP(0x0034)  // PLL 倍频器寄存器
#define REFDV   DVUCP(0x0035)  // PLL 分频器寄存器
#define CLKSEL  DVUCP(0x0039)  // 时钟选择寄存器
#define PLLCTL  DVUCP(0x003A)  // PLL 控制寄存器
#define CRGFLG  DVUCP(0x0037)  // CRG 标志寄存器
```

### 6.2 volatile 关键字

**为什么使用 volatile**:
- 防止编译器优化寄存器访问
- 确保每次读取都从硬件读取
- 确保每次写入都立即写入硬件

**示例**:
```c
// 不使用 volatile（错误）
unsigned char* TFLG = (unsigned char*)0x004E;
*TFLG = 0x01;  // 可能被优化掉

// 使用 volatile（正确）
volatile unsigned char* TFLG = (volatile unsigned char*)0x004E;
*TFLG = 0x01;  // 强制写入硬件
```

## 7. 定时器硬件机制

### 7.1 ECT 定时器模块

**代码位置**: `src/init.c` - `initECTTimer()`

ECT (Enhanced Capture Timer) 提供 8 个独立通道：

```c
void initECTTimer(){
    // 1. 配置中断使能
    TIE = 0x21;  // BIT0: 通道 0 中断使能, BIT5: 通道 5 中断使能
    
    // 2. 清除所有标志
    TFLG = ONES;      // 清除通道标志
    TFLGOF = ONES;    // 清除溢出标志
    
    // 3. 启用定时器
    TSCR1 = 0x80;     // BIT7: 定时器使能
    
    // 4. 配置预分频器
    TSCR2 = 0x84;     // BIT2: 溢出中断使能, BIT3-0: 预分频器 = 4
    // 定时器频率 = 40MHz / 16 = 2.5MHz
    // 每个计数 = 0.4μs
    
    // 5. 配置通道模式
    TIOS = 0xDE;      // 0b11011110
    // BIT0: 输入捕获 (IC0 - 主 RPM)
    // BIT1: 输出比较 (OC1)
    // BIT2-4: 输出比较 (OC2-4 - 喷油器)
    // BIT5: 输入捕获 (IC5 - 次 RPM)
    // BIT6-7: 输出比较 (OC6-7 - 喷油器)
    
    // 6. 配置输入捕获边沿
    TCTL3 = 0x0C;     // IC5 双边沿捕获
    TCTL4 = 0x03;     // IC0 双边沿捕获
}
```

### 7.2 输入捕获模式

**工作原理**:
1. **边沿检测**: 硬件检测输入引脚边沿（上升/下降/双边）
2. **捕获时间**: 硬件自动将 `TCNT` 值复制到 `TCx` 寄存器
3. **设置标志**: 硬件设置 `TFLG` 对应位
4. **触发中断**: 如果中断使能，触发中断

**代码示例**:
```c
void PrimaryRPMISR(){
    TFLG = 0x01;  // 清除通道 0 标志
    
    // 读取捕获的时间值
    unsigned short edgeTimeStamp = TC0;
    
    // 读取当前计数器值
    unsigned short codeStartTimeStamp = TCNT;
    
    // 计算延迟
    unsigned short latency = codeStartTimeStamp - edgeTimeStamp;
}
```

### 7.3 输出比较模式

**工作原理**:
1. **设置时间**: 软件将目标时间写入 `TCx` 寄存器
2. **比较匹配**: 硬件持续比较 `TCNT` 和 `TCx`
3. **触发动作**: 匹配时，硬件改变输出引脚电平
4. **设置标志**: 硬件设置 `TFLG` 对应位
5. **触发中断**: 如果中断使能，触发中断

**代码示例**:
```c
// 配置输出比较动作
TCTL1 = 0x30;  // BIT5-4: OC2 匹配时输出高电平
TCTL2 = 0x03;  // BIT1-0: OC0 匹配时输出低电平

// 设置比较时间
TC2 = TCNT + pulseWidth;  // 在 pulseWidth 时间后触发

// 启用中断
TIE |= 0x04;  // BIT2: 通道 2 中断使能
```

### 7.4 定时器溢出处理

**代码位置**: `src/realtimeISRs.c` - `TimerOverflow()`

```c
void TimerOverflow(){
    TFLGOF = 0x80;  // 清除溢出标志
    
    // 扩展 32 位时间戳的高位
    timerExtensionClock++;
}
```

**32 位时间戳**:
- `TCNT`: 16 位，范围 0-65535
- `timerExtensionClock`: 16 位溢出计数器
- 组合成 32 位时间戳

## 8. ADC 硬件机制

### 8.1 ADC 模块配置

**代码位置**: `src/init.c` - `initIO()`

```c
void initIO(){
    // 配置 ADC 模块
    ATD0CTL2 = 0xC0;  // BIT7: 模块使能, BIT6: 中断标志自动清除
    ATD0CTL3 = 0x40;  // BIT6: 序列长度 = 8 个通道
    ATD0CTL4 = 0x73;  // BIT7-4: 预分频器 = 7, BIT3-0: 采样周期 = 3
    // ADC 时钟 = 40MHz / (2 * (7+1)) = 2.5MHz
    // 采样周期 = 4 * (3+1) = 16 个 ADC 时钟周期
    
    ATD0CTL5 = 0xB0;  // BIT7: 多路复用, BIT6: 扫描模式, BIT4: 右对齐
    // 开始转换序列
}
```

### 8.2 ADC 转换流程

**硬件流程**:
1. **触发转换**: 写入 `ATD0CTL5` 触发转换序列
2. **选择通道**: 硬件自动选择通道 0-7
3. **采样**: 硬件在指定时间内采样模拟信号
4. **转换**: 硬件将模拟值转换为数字值
5. **存储结果**: 结果存储在 `ATD0DRx` 寄存器
6. **设置标志**: 硬件设置 `ATD0STAT0` 标志位
7. **触发中断**: 如果中断使能，触发中断（当前代码未使用）

**代码示例**:
```c
void sampleEachADC(ADCArray *Arrays){
    // 直接读取转换结果（转换已在后台完成）
    Arrays->IAT = ATD0DR0;  // 通道 0: 进气温度
    Arrays->CHT = ATD0DR1;  // 通道 1: 缸盖温度
    Arrays->TPS = ATD0DR2;  // 通道 2: 节气门位置
    Arrays->EGO = ATD0DR3;  // 通道 3: 氧传感器
    Arrays->MAP = ATD0DR4;  // 通道 4: 歧管压力
    Arrays->AAP = ATD0DR5;  // 通道 5: 大气压力
    Arrays->BRV = ATD0DR6;  // 通道 6: 电池电压
    Arrays->MAT = ATD0DR7;  // 通道 7: 歧管温度
}
```

### 8.3 ADC 精度和分辨率

**10 位 ADC**:
- 分辨率: 1024 级 (0-1023)
- 参考电压: 5V（典型值）
- 最小分辨率: 5V / 1024 ≈ 4.88mV

**数据格式**:
- 右对齐: 低 10 位有效，高 6 位为 0
- 左对齐: 高 10 位有效，低 6 位为 0
- 当前代码使用右对齐模式

## 9. 串口硬件机制

### 9.1 SCI 模块配置

**代码位置**: `src/init.c` - `initSCIStuff()`

```c
void initSCIStuff(){
    // 1. 设置波特率
    SCI0BD = fixedConfigs1.serialSettings.baudDivisor;
    // 波特率 = 总线频率 / (16 * baudDivisor)
    // 例如: 40MHz / (16 * 13) ≈ 192307 baud ≈ 19200 baud
    
    // 2. 配置控制寄存器 1
    SCI0CR1 = 0x13;
    // BIT4: M = 1 (9 位数据模式)
    // BIT1: PE = 1 (奇偶校验使能)
    // BIT0: PT = 1 (奇校验)
    
    // 3. 配置控制寄存器 2
    SCI0CR2 = 0x2C;
    // BIT5: RIE = 1 (接收中断使能)
    // BIT3: TE = 1 (发送使能)
    // BIT2: RE = 1 (接收使能)
}
```

### 9.2 串口发送流程

**硬件流程**:
1. **写入数据**: 软件写入 `SCI0DRL` 寄存器
2. **硬件发送**: 硬件自动发送数据位、校验位、停止位
3. **设置标志**: 发送完成后，硬件设置 `TDRE` (发送数据寄存器空) 标志
4. **触发中断**: 如果中断使能，触发发送中断

**代码位置**: `src/commsISRs.c` - `SCI0ISR()`

```c
void SCI0ISR(){
    // 检查发送中断
    if(SCI0SR1 & SCISR1_TDRE){  // 发送数据寄存器空
        if(TXPacketLengthToSendSCI0 > 0){
            // 发送下一个字节
            SCI0DRL = *TXBufferCurrentPositionSCI0;
            TXBufferCurrentPositionSCI0++;
            TXPacketLengthToSendSCI0--;
        }else{
            // 发送完成，禁用发送中断
            SCI0CR2 &= SCICR2_TX_ISR_DISABLE;
        }
    }
}
```

### 9.3 串口接收流程

**硬件流程**:
1. **检测起始位**: 硬件检测起始位下降沿
2. **采样数据**: 硬件在每个位时间中点采样数据位
3. **存储数据**: 接收完成后，数据存储在 `SCI0DRL` 寄存器
4. **设置标志**: 硬件设置 `RDRF` (接收数据寄存器满) 标志
5. **触发中断**: 如果中断使能，触发接收中断

**代码位置**: `src/commsISRs.c` - `SCI0ISR()`

```c
void SCI0ISR(){
    // 检查接收中断
    if(SCI0SR1 & SCISR1_RDRF){  // 接收数据寄存器满
        unsigned char rawValue = SCI0DRL;  // 读取接收的数据
        
        // 处理转义字符
        if(RXStateFlags & RX_ESCAPE_NEXT){
            RXStateFlags &= RX_CLEAR_ESCAPE_NEXT;
            rawValue ^= 0x20;  // 反转转义位
        }else if(rawValue == ESC_BYTE){
            RXStateFlags |= RX_ESCAPE_NEXT;
            return;
        }
        
        // 处理数据包
        if(rawValue == START_BYTE){
            resetReceiveState(CLEAR_ALL_SOURCE_ID_FLAGS);
            return;
        }
        
        // 存储数据
        receiveAndIncrement(rawValue);
        
        // 检查结束字节
        if(rawValue == STOP_BYTE){
            RXStateFlags |= RX_READY_TO_PROCESS;
        }
    }
}
```

### 9.4 串口数据包格式

**数据包结构**:
```
[START] [FLAGS] [PAYLOAD_ID_H] [PAYLOAD_ID_L] [LENGTH_H] [LENGTH_L] [DATA...] [CHECKSUM] [STOP]
```

**转义机制**:
- `START_BYTE` (0x55) 和 `STOP_BYTE` (0xAA) 是特殊字节
- 如果数据中包含这些字节，需要转义
- 转义方法: 先发送 `ESC_BYTE` (0x7D)，然后发送 `原始字节 ^ 0x20`

## 10. PWM 硬件机制

### 10.1 PWM 模块配置

**代码位置**: `src/init.c` - `initIO()`

```c
void initIO(){
    // 配置 PWM 模块
    PWME = 0x7F;      // BIT0-6: 启用 PWM 通道 0-6
    PWMCLK = ZEROS;   // 使用时钟 A 和 B（最快时钟源）
    PWMPRCLK = ZEROS; // 预分频器 = 1（最快）
    
    // 配置各通道周期和占空比
    PWMPER0 = 0xFF;   // 通道 0 周期 = 255
    PWMDTY0 = 0x00;   // 通道 0 占空比 = 0（初始关闭）
    // ... 其他通道
}
```

### 10.2 PWM 工作原理

**硬件流程**:
1. **计数器递增**: 硬件计数器从 0 递增到 `PWMPERx`
2. **比较匹配**: 当计数器等于 `PWMDTYx` 时，输出翻转
3. **周期复位**: 当计数器等于 `PWMPERx` 时，计数器复位，输出翻转
4. **重复**: 重复上述过程

**PWM 频率计算**:
```
PWM频率 = 总线频率 / (预分频器 * PWMPERx)
例如: 40MHz / (1 * 255) ≈ 156.86 kHz
```

**占空比计算**:
```
占空比 = (PWMDTYx / PWMPERx) * 100%
例如: PWMDTYx = 128, PWMPERx = 255 → 占空比 = 50%
```

### 10.3 PWM 应用

**代码位置**: `src/utils.c` - `adjustPWM()`

```c

    // 设置占空比（根据通道选择寄存器）
    switch(channel){
        case 0: PWMDTY0 = dutyValue; break;
        case 1: PWMDTY1 = dutyValue; break;
        // ... 其他通道
    }
}
```

## 11. Flash 存储器机制

### 11.1 Flash 组织结构

**代码位置**: `src/memory.x`

Flash 分为多个区域：

```
线性 Flash:
├── 0x0400 - 0x77FF: text1 (初始化代码)
├── 0x7800 - 0x7BFF: fixedconf1 (固定配置 1)
├── 0x7C00 - 0x7FFF: fixedconf2 (固定配置 2)
└── 0xC000 - 0xF7FF: text (主程序代码)

分页 Flash:
├── 0x3F0000 - 0x3F3FFF: ppage38 (16KB)
├── 0x3F4000 - 0x3F5FFF: fpage39 (8KB)
├── 0x3F6000 - 0x3F7FFF: dpage39 (8KB)
├── 0x3F8000 - 0x3F9FFF: fpage3A (8KB)
└── ... (更多页面)
```

### 11.2 Flash 写入机制

**代码位置**: `src/flashWrite.c`

Flash 写入需要特殊流程：

```c
void writeFlashBlock(void* address, void* data, unsigned short length){
    // 1. 解锁 Flash
    FCLKDIV = 0x30;  // 设置 Flash 时钟分频器（只能写一次）
    
    // 2. 擦除扇区
    FSTAT = 0x30;    // 清除错误标志
    FCMD = 0x40;     // 擦除命令
    FSTAT = 0x80;    // 开始擦除
    while(!(FSTAT & 0x80));  // 等待完成
    
    // 3. 写入数据
    unsigned char* flashAddr = (unsigned char*)address;
    unsigned char* dataAddr = (unsigned char*)data;
    for(unsigned short i = 0; i < length; i++){
        FSTAT = 0x30;  // 清除错误标志
        *flashAddr = *dataAddr;  // 写入数据（触发编程）
        FSTAT = 0x80;  // 开始编程
        while(!(FSTAT & 0x80));  // 等待完成
        flashAddr++;
        dataAddr++;
    }
}
```

**Flash 特性**:
- **只能从 1 写 0**: Flash 位只能从 1 变为 0
- **需要擦除**: 要将 0 变为 1，必须先擦除整个扇区
- **扇区大小**: 通常为 512 字节或 1KB
- **写入时间**: 每个字节写入需要几微秒

### 11.3 Flash 保护

**保护机制**:
- **向量保护**: 中断向量表区域受保护，防止意外擦除
- **配置保护**: 固定配置区域可以设置写保护
- **启动保护**: 某些区域在启动后自动保护

## 12. 分页内存系统

### 12.1 PPAGE 寄存器

**代码位置**: `src/inc/9S12C128.h` 第 114 行

```c
#define PPAGE DVUCP(0x0030)  // 页面寄存器
```

**工作原理**:
- `PPAGE` 寄存器选择当前页面

```
PPAGE = 0x3A → 0x4000-0x5FFF 映射到 0x3F8000-0x3F9FFF
```

## 13. 实时时钟 (RTI)

### 13.1 RTI 配置

**代码位置**: `src/init.c` - `initInterrupts()`

```c
void initInterrupts(){
    // 配置 RTI 周期
    RTICTL = 0x10;
    // BIT7-4: 预分频器 = 1 (除以 2^1 = 2)
    // BIT3-0: 模数计数器 = 0 (除以 2^0 = 1)
    // RTI 周期 = 1 / (8MHz / 2^1 / 2^0) = 1 / 4MHz = 0.25μs * 512 = 128μs
    
    // 启用 RTI 中断
    CRGINT |= 0x80;  // BIT7: RTI 中断使能
    
    // 清除 RTI 标志
    CRGFLG = 0x80;   // BIT7: RTI 标志
}
```

### 13.2 RTI 中断处理

**代码位置**: `src/realtimeISRs.c` - `RTIISR()`

```c
void RTIISR(){
    CRGFLG = 0x80;  // 清除 RTI 标志
    
    // 更新实时时钟
    realTimeClockTenths++;
    if(realTimeClockTenths >= 10){
        realTimeClockTenths = 0;
        realTimeClockMillis++;
        
        if(realTimeClockMillis >= 1000){
            realTimeClockMillis = 0;
            realTimeClockSeconds++;
            
            if(realTimeClockSeconds >= 60){
                realTimeClockSeconds = 0;
                realTimeClockMinutes++;
            }
        }
    }
}
```

**RTI 用途**:
- **实时时钟**: 提供毫秒级时间基准
- **超时检测**: 检测传感器读取超时
- **周期性任务**: 执行周期性任务（如 LED 闪烁）

## 17. 性能优化

### 17.1 代码位置优化

**代码段分配**:
- **TEXT1**: 初始化代码（线性 Flash）
- **TEXT**: 主程序代码（线性 Flash）
- **分页 Flash**: 表格数据（不常用）

**优势**:
- 常用代码在快速访问的线性 Flash
- 表格数据在分页 Flash，节省线性空间

### 17.2 数据访问优化

**双缓冲机制**:
- 避免数据竞争
- 减少原子操作时间
- 提高实时性

**寄存器缓存**:
- 频繁访问的寄存器值缓存在变量中
- 减少寄存器访问次数

### 17.3 中断优化

**中断优先级**:
- 关键中断（位置解码）最高优先级
- 非关键中断（通信）低优先级

**中断处理时间**:
- ISR 中只做必要工作
- 复杂计算放在主循环
- 使用标志位通知主循环

- 清除同步标志

- 等待重新同步

**检测方法**:
- 低电压中断
- 电池电压 ADC 读数

**处理策略**:
- 记录低电压事件
- 降低功耗
